# Base de données 1 — L1

Parcours étudiant consacré aux fondamentaux des bases de données, à la modélisation et au SQL. Il complète les supports historiques du dépôt sans les remplacer.

Les scripts et exemples utilisent le scénario pédagogique de la clinique Santé Plus. Les noms, coordonnées, dates et consultations font partie de ce cas d’étude; ils ne proviennent pas d’un export de patients. L’audit des scripts n’a relevé aucun mot de passe, jeton, clé ou adresse électronique.
